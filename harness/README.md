# harness

발표 데모를 안전하게 돌리기 위한 도구 모음. 서비스 이름은 가칭 "눈치페이(NunchiPay)".

## 명령 (web-poc/ 에서)
| 명령 | 용도 |
|---|---|
| `npm run build:data` | `../delivery`, `../predictions` CSV를 `public/data/data.json`으로 변환 (KPI는 예측 CSV에서 다시 계산) |
| `npm test` | 데이터 재생성 후 스모크 테스트 (13쪽 사례 3건, 조회 규칙, 제시 연봉 선택, KPI = README 검증값) |
| `npm run dev` | 개발 서버. `#/`는 사업 설명 랜딩(문제 → 해결 → 사업모델 → 증명 → 시범 운영), `#/app`은 체험 도구, `#/pitch`는 시범 운영 안내 |
| `npm run build && npm run preview` | 발표용 정적 빌드 (오프라인 동작) |

## 견적 규칙 (발표자료 13쪽 기준)
간편 조회형(직무·지역·경력만 입력)은 아래 순서로 값을 정한다. 코드는 `src/lib/lookup.ts`.
1. 납품 사례 13건(`delivery/client_benchmark_sample.csv`)은 납품된 값을 그대로 쓴다. 뉴저지 화학자(디렉터)는 제공 보류.
2. 같은 직무·주·경력 공고가 30건 이상이면 관측 범위(캘리포니아 개발자 79건: $142,000~$202,100).
3. 아니면 모델 견적 격자(뉴욕 회계사 19건: 모델로 보완, $82,800~$111,500). 격자에도 없으면 제공 보류.
- 현재 기준 환산은 임금 상승(ECI ×1.078)을 반영한 참고값이다. 사례 13건은 납품된 환산값을 쓴다.
- 정확도 숫자 19.3%/50.0%/52.5%는 **공고 초안형** 기준이다. 이 PoC의 간편 조회형은 셀 조회 대비 5.3%(`model/metrics/business.json`의 B 조회 견적)다. 공고 초안형 견적은 PoC에 포함하지 않았다.

## 페이지 구성
- 랜딩(`#/`): 사업 설명 한 흐름. 버튼은 "시범 운영 안내 보기" 하나를 앞세운다. 첫 화면의 움직이는 장면(`src/demo/QuoteDemo.tsx`)은 실제 견적 도구의 카드(`src/features/quote/cards.tsx`)를 그대로 쓴다.
- 수익구조는 금액 없이 단계(시범 운영 → 정식 도입, 가격은 시범 결과 후 협의)로만 표시한다. 발표자료에 가격 근거가 없다.
- 납품 사례 카드는 누르면 `#/app?soc=&state=&exp=`로 그 조건의 체험 화면이 열린다.
- 체험 도구(`#/app`): 조건 선택 → 범위·확신도 → 제시 연봉 → 공고에 적기 한 방향 흐름. 기존 방식 비교와 정확도는 "근거 더 보기"로 접어 둔다.

## 발표 전 체크리스트

- [ ] 1분 시연: 랜딩 첫 화면의 움직이는 장면 → 문제 → 사업모델 한 장 → 증명 → "견적 체험"에서 CA 개발자, 뉴욕 회계사, 뉴저지 화학자(보류) 순으로 조작
- [ ] 13쪽 사례 3건 확인: 캘리포니아 개발자(관측), 뉴욕 회계사(모델 보완), 뉴저지 화학자 디렉터(보류)

## 한계 (질문 대비)
- 실시간 추론이 아니라 사전 계산한 격자 조회다.
- 사업 금액은 게시 연봉 기준 모의 값이다. 가격은 미정이다.
- SOC 매칭 정확도 73.5% (표본 200건, 사람 검수 없음).
- 서비스 이름 "눈치페이"는 가칭이며 상표 조사를 하지 않았다.
